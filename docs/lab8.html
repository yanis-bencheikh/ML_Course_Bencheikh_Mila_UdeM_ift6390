PyTorch and backpropagation

The lab opens with backpropagation done by hand, without any library, on the smallest network that has a hidden layer. PyTorch only arrives afterwards, on the same network and the same numbers.

As soon as w₁ is negative (with x = 2), z₁ = w₁·x is negative, ReLU outputs h₁ = 0 and its local slope is 0. The chain for w₁ contains that 0, so ∂L/∂w₁ = 0 and ∂L/∂v₁ = 0: the update w₁ ← w₁ − η·0 leaves the weight where it is. In PyTorch the same thing appears as a .grad equal to 0 after backward().

Why a network needs a non-linearity

240 points in four clusters, the XOR layout: no straight line separates red from blue. The network has 2 inputs, one hidden layer and 1 output, and is trained in your browser, with the backward pass written by hand in about thirty lines of JavaScript.

No. Without an activation, the hidden layer computes W x + b and the output computes v·(W x + b) + c, which is again of the form a·x + d: a single line, however many neurons or epochs. The boundary stays straight and accuracy stays near 50 %. With ReLU each hidden neuron contributes one bend, and a few bends are enough for XOR. One hidden neuron with ReLU is not enough: try it.
