How the material is built

Predict, then check. Each simulation is preceded by a question the student answers before touching a slider, and followed by the answer.

One idea at a time. One sentence per cell in large type, at most one paragraph before the next figure or code cell.

No skipped step. Each derivative is obtained line by line, each line with its justification, first for a single weight with real numbers, then in matrix form.

Checked by execution. Every notebook runs from top to bottom without error, every gradient is compared with a finite difference, and the mathematics of these pages is covered by an automated test.
